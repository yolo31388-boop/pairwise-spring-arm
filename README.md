# pairwise-spring-arm

第三人称相机贴着墙时镜头突然穿进几何体，弹簧臂的碰撞检测只测理想位置，没沿相机到角色的整段射线做扫掠；角色传送后相机保留旧插值，画面从旧位置飞过来；近平面裁剪把贴墙的相机切成黑屏，代码却把 near 固定为 0.1；多相机分屏时弹簧臂共享一份平滑状态，左右视角互相拉扯；过场动画切回 gameplay 时相机 blend 没清抖动偏移，镜头带余震；相机碰撞层把触发器也算进去，走过草丛镜头被弹开；高低速切换时阻尼按帧率算，120fps 下相机比 60fps 更硬；屏幕震动叠加在最终矩阵上，碰撞扫掠却用未震动的位置；角色被击退时相机跟随目标点滞后，准星与角色分离；回放系统只记录相机位置没记录弹簧臂长度，重放镜头贴墙穿模。gameplay/spring_arm_camera.py 是核心，tests/test_spring_arm_camera.py 15个红。要修的是：整段扫掠并取最近命中；传送时重置插值；近平面随碰撞距离收缩；多相机独立平滑状态；过场切回清抖动；碰撞层排除触发器；阻尼按时间步归一；扫掠用震动前位置；跟随点与准星分离；回放补记臂长。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
